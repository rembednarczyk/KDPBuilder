# Bundled font

**Baloo2-ExtraBold.ttf** is a static instance (weight 800) of **Baloo 2**,
generated from the upstream variable font with fontTools instancer.

- Family: Baloo 2 (no Reserved Font Name in its license).
- Copyright 2019 The Baloo 2 Project Authors (https://github.com/EkType/Baloo2).
- Licensed under the SIL Open Font License, Version 1.1. See `OFL.txt`.
- Covers Polish diacritics (ą ć ę ł ń ó ś ź ż and uppercase).

Used as the default cover title font (rounded, bold, playful) for the niche.
Body text and the back-cover blurb still use DejaVu for readability.
